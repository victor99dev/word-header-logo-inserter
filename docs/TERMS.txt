Cabecalho Logo Inserter

Última atualização: agosto de 2026.

Este software foi criado como um projeto de estudo e experimentação.

A aplicação surgiu de uma necessidade prática de inserir automaticamente uma logomarca no cabeçalho de documentos já gerados por outro processo.

O projeto também foi utilizado como estudo sobre publicação e distribuição de uma aplicação Windows, incluindo geração de executável, criação de instalador com Inno Setup e distribuição por meio de GitHub Releases.
